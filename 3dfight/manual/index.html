1. ルールと勝敗条件（Phase 3 トーナメント対応）

90年代ローポリ風3D動物格闘ゲーム（Phase 3 / 全9体参戦）です。正方形の武道場リング（-10 ～ +10）の上で、固有の思考AIを持つ動物ファイター同士が戦います。2ラウンド先取（1ラウンド60秒）で勝利となります。

  • ANIMAL BUDOKAI（全員勝ち抜き）： オモテは自分以外のレギュラー8体全員と戦う全8連戦！制覇後のヒーローインタビュー中に猛獣四天王全員＋極北の帝王しろくまが乱入し、裏5連戦が開幕します。
  • SINGLE MATCH（フリー対戦）： 好きな自キャラと難易度（EASY / NORMAL / HARD）を選んで1戦する練習・検証モード。
  • K.O.勝ち： 相手の体力（HP）を 0 にする。
  • リングアウト（RING OUT）勝ち： 赤い境界線の外へ相手を吹き飛ばす、または落下させる。
  • タイムオーバー： 制限時間終了時に残りHP割合が多い方の勝利。

3. 戦闘の基本：三すくみシステム

打撃（Z / X / C / V）

「投げ」に勝つ！ 相手が投げを狙っている最中に打撃を当てると COUNTER! となり、ダメージが1.25倍になります。

防御／ガード（S）

「打撃」を防ぐ！ 押している間は打撃ダメージを完全に防ぎます。ただし強い攻撃を受けると少しノックバックします。

投げ（A）

「防御」を崩す！ 接近戦で相手のガードを無視して掴み、巴投・大外刈・一本背負投・小外刈・肩車の5種の柔道技がランダムで発動します（巴投は後方へ投げるため逆転リングアウトも可能）。

5. タブレット・スマートフォン操作

◯

方向操作（◯ドラッグ＝3D 4方向移動）： 円の中の ◯ を上下左右へドラッグすると、前後・奥手前の4方向へ自由に3D移動できます。指を離すと中央へ戻ります。

専用 JUMP ＆ かがむ ボタン： 右側の JUMP でジャンプ、かがむ でしゃがみます（かがむ は長押しでも、短タップでON/OFF切替でも使え、しゃがみ状態＋投げ で確定「巴投」が出ます）。

マルチタッチ対応： 左手で ◯ をドラッグしながら、右手で攻撃や SP1(Q)・SP2(W)・防御 を同時に押せます。

表示切替・左右反転： 画面上部の PAD: AUTO/ON/OFF で表示切替、配置: 左◯/右◯ で利き手に合わせた左右入替が可能です。

7. 動作環境・注意事項

  • 推奨ブラウザ： PC版 Google Chrome / Android版 Google Chrome / iOS版 Safari
  • 画面サイズ： アドレスバー・タブバー・セーフエリアに追従する全画面設計です。画面回転時も自動調整されます。
  • 誤操作防止： ゲーム盤面と操作パッド上のスワイプスクロール・ピンチズームは無効化していますが、上部ボタン・ポーズ画面・マニュアルリンクは通常通りタップできます。
  • キャッシュ無効化： 常に最新プログラムで動作するよう、HTMLメタタグ・起動時キャッシュ削除・BFCacheリロード制御を組み込んでいます。

※ ローカルPC上でテストする場合は、ES Modules仕様のため file:// 直開きではなく静的HTTPサーバー経由でアクセスしてください。
