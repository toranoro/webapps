■ 起動方法 (Windows)
1. 「start_game.bat」をダブルクリックしてください。
   (Python 3 が必要です。キャッシュ無効化サーバーが 127.0.0.1:8080 で起動し、
    自動でブラウザが開きます)

2. コマンドラインから起動する場合:
   python serve_nocache.py 8080
   を実行し、ブラウザで http://127.0.0.1:8080/ を開いてください。

■ 9種類の動物レーサー ＆ マシン選択 (車＆バイク！)
GAMESTART 後、3×3 パネルで動物レーサーを選べます（全車同一走行性能・バイクはコーナーで深く傾きます）！
- I / J / K / L (または矢印キー): 動物を選択 → Enter (またはクリック) で HUMAN 決定（3回フラッシュ）！
- 決定後、COM1・COM2・COM3 が1体ずつルーレット＆3回フラッシュで確定 → 全員決定後に「🏁 このメンバーで出走！ [Enter]」ボタンで発走！
  🐻 クマ / 🐧 ペンギン / 🐰 ウサギ (バイク) / 🦊 キツネ / 🐼 パンダ (バイク)
  🦁 ライオン / 🐺 オオカミ (バイク) / 🐸 カエル / 🐱 ネコ (バイク)

■ オリジナルアイテム（パワーカプセルから入手）
- 🚀 ミニロケット    : 一気にスピードアップ！(ダートも減速なし)
- 💥 トゲボール      : 前方へ鉄球発射！壁に反射し、当たった相手をスピン！
- 🛢️ ツルツルオイル  : 後方へオイル缶＆オイル溜まり設置！踏むとスピン！
- 👑 キングクラウン  : 6秒間虹色に光って無敵＆体当たりでライバル吹き飛ばし！

■ 全6カップ × 4ステージ (全24コース) ＆ グランプリ表彰式
タイトル画面でカップをタブ（または J/L キー）で選んでスタート！
1. 🌿 ルーキー・カップ: グリーン・サーキット / マッド・スワンプ / マグマ・キャッスル / クロスオーバー・ファイナル
2. 🌊 マリン・ウェーブ・カップ: サンセット・ビーチダート / オーシャン・ブリッジ / ディープシー・トンネル / ハーバー・タウン＆シップ
3. ⛰️ アルパイン・カップ: フォレスト・スラローム / ワインディング・パス / マグマ・マインシャフト / スカイ・ピーク・リッジ
4. ❄️ アイシー・キングダム・カップ: フローズン・タウン / アイスリバー・フォレスト / ウィンター・アルパイン / ブリザード・サーキット
5. 🌃 ネオンナイト・カップ: サイバー・ハイウェイ / レーザー・ブリッジ / メトロ・ループジャンクション / エレクトロ・アリーナ
6. 🎪 アミューズメント・カップ: トイブロック・レールウェイ / ゼリー＆バウンド・パーク / スイート・ケーキ・キャッスル / レインボー・ローラーコースター
- 得点配分: 1位=10pt / 2位=6pt / 3位=3pt / 4位=1pt（全4戦累計で総合優勝＆表彰式！）

■ 操作キー
- Enter : ゲームスタート ／ キャラ決定 ／ 出走 ／ イントロスキップ ／ ポーズ中リスタート ／ 次ステージ ／ もういちど
- I/J/K/L / 矢印 : キャラ選択カーソル移動 (レース中は J/L: ハンドル, K: アイテム)
- X / Z : アクセル / ブレーキ・バック (↑ / ↓ も可)
- Space : イントロスキップ ／ ジャンプ（落とし穴・積み木飛び越え！） ＆ ドリフト ／ 表彰式からタイトルへ戻る
- V     : 下画面カメラモード切替（斜め上3D全体／斜め上中継／真上）
- M     : 効果音 ON / OFF 切替（右上ボタンでも切替可）
- Esc   : 一時停止メニュー（戻る / Enterでやり直す / リタイア）
- C / R : うしろを見る / レスキューバード隊救出（コウノトリ＆小鳥たちが紐で安全路面へ戻してくれます）
