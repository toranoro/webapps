# Project Handover: 3D KART GRAND PRIX

## 1. プロジェクト概要 (Project Overview)
ブラウザ上で動作する、オリジナル上下2画面アーケード型3Dカートレースゲーム「3D KART GRAND PRIX」のプロジェクト。
リアルな車両シミュレーターの難しさ（スピンや横転）を避け、**スフィア（球体）コライダーを用いた気持ちよいアーケード物理**、**ホップ＆ドリフトからの2段階ミニターボ（火花エフェクト）**、**お邪魔アイテム＆ダッシュパネル**、**ギミック満載の4ステージ制グランプリ＆表彰式**、**CPUライバルとの3周レースループ**を搭載している。

## 3. コア機能・ゲーム仕様 (Core Mechanics)

### 3.1 カート物理・ドライビングアクション（アーケードスフィア方式）
リアルな4輪サスペンション計算による横転を防ぐため、**「物理判定は球体（Sphere）」「見た目はカートメッシュ」**を分離して制御する。

- **物理ボディ:** `RAPIER.ColliderDesc.ball(0.95)` を動的剛体（`CCD有効`, `Friction = 0.0`, `Restitution = 0.1`）として動かし、下方向レイキャストで接地・路面種別（舗装路 / ダート / ダッシュパネル）・路面法線を取得する。
- **見た目の追従:** カートの3Dモデル（シャーシ、ドライバー、回転する4輪、ハンドル、マフラー）は物理球体の中心からオフセットした位置に追従させ、路面法線へ向けて滑らかに `slerp` で傾ける（坂道やジャンプ台で自然なピッチ角がつく）。
- **基本操作:**
  - **アクセル (`X` / `↑`):** 前進方向へ加速（最高速例: `34 m/s`）。
  - **ブレーキ / バック (`Z` / `↓`):** 減速および停止後の後退。
  - **ステアリング (`J` 左 / `L` 右 または `←` / `→`):** 進行方向の旋回。カーブ時には車体ロールと前輪切れ角をアニメーションさせる。
  - **アイテム使用 (`K`):** 所持中のアイテムを発動。
- **ホップ＆ドリフト・ミニターボ（ステートマシン設計）:**
  - `Normal`: 通常走行。
  - `Hop`: `Space` 押下で小さなジャンプ（高さ約 `0.6m`、見た目上の跳ねアニメーション付き）。
  - `DriftLeft` / `DriftRight`: `Space` を押し続けながら左右どちらかにステアして着地するとドリフト状態へ移行。外側へ膨らみつつイン側へ鋭く切れ込む角度調整が可能（カウンターステアで軌道微調整）。
  - **2段階ミニターボチャージ:**
    - ドリフト継続 `0.7s` 以上で **Lv.1 ミニターボ（青い火花）**
    - ドリフト継続 `1.6s` 以上で **Lv.2 スーパーミニターボ（オレンジの火花）**
    - `Space` を離すとチャージ段階に応じた `Boost` 状態（一時的な最高速突破＋FOV拡大＋マフラー炎）へ遷移する。
  - `SpinOut`: バナナやミドリこうらに接触するとその場で1.2秒間スピンして一時減速する。

### 3.2 カメラシステム (3rd Person Chase Camera)
- **スプリングダンピング追従:** カートの進行方向ベクトル（および向き）の背後にバネダンパー補間で追従し、急ハンドル時は少し遅れて回ることでスピード感を演出する。
- **ダイナミックFOV:** ブースト発動時（ミニターボ・ダッシュボード・キノコ・スター）にカメラの視野角（FOV `62°` → `78°`）を滑らかに広げ、疾走感を出す。
- **バックミラー視点 (`C` キー):** 押している間だけ前方からカートを映し、後続のライバルやこうらを確認できる。
- **地形衝突回避 (Camera Collision):** カートからカメラ位置へのレイキャスト（`PhysicsWorld.castRay`）で壁やコース外縁とのめり込みを防ぐ。

### 3.3 サーキットコース＆ギミック (Circuit Track & Gimmicks)
- **周回サーキット生成 (`THREE.CatmullRomCurve3`):**
  - 高低差のあるS字カーブ、ヘアピンコーナー、ロングストレートを含む閉ループのコースを生成。
  - コース構成要素: 舗装アスファルト路面、赤白縁石（カーブマーカー）、外側ガードレール（衝突しても引っかからず滑る壁）、コース外の芝生/ダートエリア（進入すると最高速が約55%に低下、ブースト/スター中は無効）。
- **コースギミック:**
  - **虹色ダッシュボード（加速床）:** 通過すると即座に強ブースト発動。
  - **ジャンプ台（スロープ＆グライダー風ジャンプ）:** ストレート終盤やショートカット先に配置し、大ジャンプ＆着地演出を発生。
- **周回チェックポイント & 逆走検知:**
  - コースに沿って順序付きチェックポイントゲート（例: 8〜12分割）を配置し、順番に通過してフィニッシュラインを跨いだ場合のみ周回カウントを進める（ショートカットによる不正ラップ加算を防止）。
  - 進行方向とコース接線ベクトルの内積が負の状態が続いた場合、HUD中央に「逆走！（ぎゃくそう）」警告を表示する。

### 3.4 アイテム＆CPUライバル＆レース進行 (Items, CPU AI & Race Loop)
- **？アイテムボックス:** コース横並びで複数箇所に配置。接触するとルーレット演出（約1.0秒）を経てアイテムを1つ獲得し、数秒後に再出現する。
- **実装アイテム:**
  1. **ダッシュキノコ:** 即座に強力なブーストを発動（ダートを突っ切るショートカットが可能）。
  2. **ミドリこうら:** カート前方に高速射出され、ガードレールに当たると反射しながら直進し、当たったカートを `SpinOut` させる（最大バウンド回数制限あり）。
  3. **バナナ:** カート後方に設置（前方投げもオプション可）。踏んだカートを `SpinOut` させる。
  4. **スーパースター:** 約6秒間無敵＆虹色点滅状態になり、最高速アップ＋ダート減速無効＋体当たりした相手を弾き飛ばす。
- **CPUライバル（3台）:**
  - コース上のウェイポイント列（わずかな左右ラインのばらつき付き）を追従走行するAIコントローラー。
  - レース展開が白熱するよう、プレイヤーとの距離差に応じた軽度なラバーバンディング（速度補正）を持たせる。
- **レースループ（3周制）:**
  - スタートグリッド整列 → `3・2・1・GO!` カウントダウン（`GO` タイミングでのアクセルでロケットスタート判定も可能） → 3周走行 → フィニッシュ演出（最終順位 1st〜4th、各ラップタイム、合計タイム、リスタートボタン）。

## 6. 遵守事項・開発上の制約条件 (Constraints & Best Practices)
新プロジェクトとして着手する際も、以下の制約を厳守すること。

- **参照フォルダ制限:** 指定されたプロジェクトフォルダ外へのファイル参照・アクセスを行わないこと（必要な場合は必ずユーザーの許可を得ること）。Node.js がグローバル環境に無い場合は、ワークスペース内の `.tools/node` 等のローカル領域に構築すること。
- **キャッシュ完全無効化:** すべての HTML に no-cache メタタグを記載し、`vite.config.ts` および `serve_nocache.py` で `Cache-Control: no-store, no-cache, must-revalidate` を返すこと。
- **WASM非同期初期化とフレームレート非依存:** `await RAPIER.init()` 完了後にワールドを生成し、移動・タイマーには上限クランプ付き `deltaTime`（`Math.min(dt, 0.05)`）を使用すること。
- **引き継ぎ・記録・マニュアル・配布物の維持:**
  - `Update.txt` に各 Phase・改修内容・検証結果を逐次記録する。
  - `manual/` にふりがな (`<ruby>`)・図解付きのオンラインマニュアルを生成し、HUD からワンクリックで開けるようにする（表記は「マニュアル」）。
  - `dist/` に配布用一式（ビルド成果物 + `manual/` + `serve_nocache.py` + `start_game.bat` + `README.txt`）を揃える。
  - 開発完了後、引き継ぎドキュメントに最新のパラメータ・起動手順を反映する。

### 7.3 ローカルビルド・起動・引き継ぎ手順
1. **Node.js 環境**: ワークスペース内 `.tools/node-v20.18.1-win-x64` にポータブル Node.js v20.18.1 と `.tools/npm-cache` を配置済み。PowerShell で以下を実行してビルド可能:
   ```powershell
   $env:PATH = "$PWD\.tools\node-v20.18.1-win-x64;$env:PATH"
   $env:npm_config_cache = "$PWD\.tools\npm-cache"
   npm.cmd run typecheck
   npm.cmd run build
   ```
   （※ `vite build` は `dist/` を空にして再生成するため、`dist/assets/music` を一時退避して再ビルドし、完了後に `dist/assets/music`, `manual/`, `serve_nocache.py`, `start_game.bat`, `README.txt`, `Update.txt`, `HANDOVER.md` を戻す／再コピーすること）
2. **配布版起動**:
   - `dist\start_game.bat` を実行、または `python dist\serve_nocache.py 8080` 実行後、`http://127.0.0.1:8080/` を開く。
3. **テスト用デバッグ API (`window.__kartGame`)**:
   - `getState()`, `selectCup(cupId)`, `openCharSelect(stageId?)`, `selectCharacter(humanIndex, immediate?)`, `startRace(stageId?)`, `skipIntro()`, `loadStage(stageId)`, `nextStageOrCeremony()`, `enterCeremony()`, `togglePause()`, `toggleMute()`, `retireToTitle()`, `triggerRescue()`, `cycleBottomView()`, `giveItem(item)`, `setInput(override)`, `debugCompleteRace()`, `restart()` を利用して自動テスト可能。
