# プロジェクト引き継ぎ書（HANDOVER.md）：Web囲碁アプリ（九路盤・囲碁道場）

本書は、Web囲碁アプリケーション「九路盤・囲碁道場」の設計仕様、アーキテクチャ、実装機能、マルチデバイス対応、および運用・保守・拡張に関する引き継ぎ資料一式です。開発環境の移行や引き継ぎ後も、本書を参照することでスムーズに開発・運用を継続できます。

---

## 1. プロジェクト概要・目的

* **アプリケーション名:** 九路盤・囲碁道場 (Igo Dojo 9x9)
* **目的:** ブラウザ上で動作する軽量・高視認性・高機能な九路盤（9×9）囲碁Webアプリケーション。
* **ターゲットユーザー:**
  1. **初心者（開発者本人）:** 囲碁の基本（石の取り方、アタリ、生き死に、陣地計算）をガイドやアシスト付きで楽しく学びたい。
  2. **上級者（60代の知人）:** 見やすい盤面でサクッと手応えのある九路盤対局（MCTS AI戦）や感想戦を楽しみたい。
* **基本アーキテクチャ:**
  * **完全ビルド不要:** Node.jsやnpm、webpack/vite等の外部バンドラーを一切使用せず、Pure HTML5 / CSS3 / Vanilla JavaScript (ES6 Modules) のみで完結。
  * 静的Webサーバーやファイル共有（NAS・ローカル共有フォルダ等）に配置するだけで即座に稼働。

## 3. 実装済み機能一覧

### 画面①：タイトル＆対局設定メニュー画面（#menu-screen）
1. **対戦モード:**
   * `人間 vs AI`: レベル別AIとの対局。
   * `人間 vs 人間 (1台共有)`: タブレットやPCを囲んで2人で交互に打つモード。
2. **AIの強さ（4段階）:**
   * `Lv.1 入門`: ランダム着手。自殺手や即取られる愚手を避け、相手のアタリ石があれば取る。
   * `Lv.2 初級`: アタリの捕獲と救出を最優先。天元・星・連結等の基本好点を考慮。
   * `Lv.3 中級`: モンテカルロ木探索（MCTS 250シミュレーション）による本格思考。
   * `Lv.4 上級`: モンテカルロ木探索（MCTS 800シミュレーション＋UCB1）。九路盤特化の勝率最大化探索。
3. **手番・置き石設定:**
   * 手番：`黒番 (先手)` / `白番 (後手・コミ付)` / `ニギリ (ランダム)`
   * 置き石（ハンデ）：`互先 (コミ6.5目)` / `2子局` / `3子局` / `4子局`（置き石時はコミ0.5目、白番先手）
4. **初心者サポート機能（個別ON/OFFスイッチ）:**
   * **アタリ警告表示:** 次に取られそうな石グループを赤枠・光輪で点滅させ、警告音を発音。
   * **着手禁止理由の通知:** 自殺手やコウの地点に着手しようとした際、理由をトースト表示。
   * **「待った」の許可:** 手番を一手（AI戦時はAIと自分の着手を合わせて二手）戻す。
   * **地合い（優勢度）予測バー:** リアルタイムで黒白の形勢を視覚的バーで表示。
   * **誤タップ防止モード:** 1タップ目で仮置きゴースト石を表示、再タップまたは「確定」で着手。
   * **着手・効果音 (Web Audio):** 石を打つ音、石を取り上げる音、アタリ警告音。

### 画面②：対局画面（#game-screen）
* **CSS Gridによる縦横両対応レイアウト（タブレット・スマホ・PC最適化）:**
  * **PC・横長画面時（Landscape）:**
    * 3カラム構成：左カラム（白番情報＋アゲハマ）、中央（9×9木目碁盤）、右カラム（黒番情報＋操作ボタン群）。
  * **タブレット縦・スマホ時（Portrait）:**
    * 上段（碁盤直上）：白番カードと黒番カードを左右2分割で横並び配置。情報がスッキリまとまり縦余白を大幅確保。
    * 中段（主役）：碁盤を限界まで最大化（`min(97vw, calc(100vh - 160px), 740px)`）。iPad縦なら最大740pxの超特大盤面。
    * 下段（碁盤直下）：操作ボタン群（「パス」「待った」「ヒント」「投了」）を横一列で配置。
    * **効果:** 画面スクロールが一切発生せず、全要素が1画面に美しく収まります。
* **碁盤サイジング・表示設計:**
  * 中央盤面エリア（`.board-center-area`）は `grid-area: board;` で中央最大化。
  * 盤面外枠は 2×2 グリッド（左上角余白、上部横座標 1〜9、左側縦座標 一〜九、中央交点グリッド）で構築されており、各マス目の直上・真横に座標文字がピタリと一致。
* **碁盤UI:**
  * 横（1〜9）、縦（一〜九）の座標ラベル。
  * 天元（4,4）および四隅（2,2 / 6,2 / 2,6 / 6,6）の星付き。
  * 最終手マーカー（直前の手に色付きサークル）。
  * ヒント表示（AIが推薦する好手交点に緑色マーカーを表示）。
* **操作系:**
  * 「パス」「待った」「💡 ヒント」「投了」「メニューへ戻る」「全画面表示」「サウンド切替」。

### 画面③：終局・地合い計算＆感想戦モード（#result-modal）
* **自動終局:** 双方が連続して「パス」を押すと自動終局（または「投了」時）。
* **地合い（陣地）自動計算:**
  * 黒の地（囲んだ目数）、白の地、ダメ（中立点）を盤面上で色分けハイライト。
  * 「地 ＋ アゲハマ ＋ コミ」を自動合算し、勝敗と目数差をダイアログ表示。
* **感想戦（棋譜再生）機能:**
  * 「初手」「1手前」「1手次」「終局」ボタンで、1手目から終局までの手順を盤面上で再現・振り返り可能。

## 4. マルチデバイス・ブラウザ対応仕様

### 対象環境
* **PC:** Google Chrome（Windows / macOS）
* **タブレット:** iPad Safari（iPadOS）
* **スマートフォン:** Android Google Chrome

### キャッシュ無効化仕様（最新版の強制適用）
ブラウザが過去のスクリプトやスタイルシートを保持して改修内容が反映されないトラブルを防ぐため、3重の対策を講じています：
1. **HTML Metaタグ:** `Cache-Control: no-cache, no-store, must-revalidate`, `Pragma: no-cache`, `Expires: 0`
2. **リソースURL:** `style.css?v=1.0.1`, `main.js?v=1.0.1` などのバージョンクエリを付与。
3. **Service Worker (`sw.js`):**
   * **Network-First戦略:** 常にネットワークから最新ファイルを取得し、成功時にキャッシュを更新。
   * **即時アクティベート:** `skipWaiting()` と `clients.claim()` により、新バージョンが即時反映。

### 画面崩れ・誤操作防止仕様
ゲームプレイ中の意図しないスクロールやズーム、誤スワイプを防ぐため、以下の対策を実施：
1. **Viewport:** `width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`
2. **CSSタッチ制御:**
   * 碁盤レイヤー: `touch-action: none;`
   * メニュー画面: `touch-action: pan-y;`（縦スクロールのみ許可）
   * 全体: `user-select: none; -webkit-user-select: none; overscroll-behavior: none;`
3. **JavaScriptジェスチャー抑止:**
   * `gesturestart`, `gesturechange`, `gestureend` の `preventDefault()`
   * 300ms以内のダブルタップ拡大防止（`touchend` 制御）

### 全画面表示・PWA対応
* **PC / Android Chrome:**
  * `requestFullscreen()` による全画面表示。
  * `beforeinstallprompt` イベントを捕捉し、「📲 アプリをインストール」ボタンを表示。
* **iPad Safari:**
  * `<meta name="apple-mobile-web-app-capable" content="yes">`
  * `<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">`
  * ホーム画面追加ガイドモーダル（共有ボタンから「ホーム画面に追加」する手順案内）を内包。

Write-Output "Distribution completed."

## 6. 今後の拡張ロードマップ（引き継ぎ用）

1. **盤面サイズ拡張（13路盤・19路盤対応）:**
   * `igo-engine.js` の `BOARD_SIZE` はコンストラクタ引数で受け取る設計になっているため、メニューでサイズ選択（9/13/19）を追加し、碁盤の星の座標設定（13路: 4-4, 10-4等、19路: 4-4, 10-10等）を拡張すれば容易に対応可能。
2. **WebAssembly / GNU Go 連携:**
   * `ai-engine.js` の `getBestMove()` は Promise を返す非同期インターフェースになっているため、将来的により強力な思考エンジン（GNU Go や KataGoのWasm版）を導入する際も、UI側の修正なしで差し替え可能。
3. **SGF棋譜ファイルのインポート／エクスポート:**
   * `this.engine.history` に全着手座標・手番・アゲハマが保存されているため、標準的なSGF（Smart Game Format）形式のテキスト出力・読み込み機能を簡単に追加できます。
