[2026-11-23] バージョン 1.0.3 タブレット・スマホ縦向きデザイン刷新＆全要素画面内収容
--------------------------------------------------------------------------------
1. 要望・課題
   - タブレット（iPad）やスマホの縦向き時、碁盤サイズが小さく感じられる。
   - 縦向き時に白や黒の状況、パスや待った等の操作ボタンが画面下に隠れてしまう。
   - タブレットで縦向き・横向きのどちらでも快適に操作できるようデザインを改善したい。

2. 改修内容（CSS Gridによる縦横両対応レイアウト）
   - 縦向きレイアウトの構造改革:
     * 上段（ヘッダー直下）: 白番カードと黒番カードを左右2分割の横並びに配置。
       コンパクトに情報（石アイコン、名前、手番、取った石数）を整理し、縦スペースを大幅節約。
     * 中段（メイン）: 碁盤エリアを縦・横の限界まで最大化。
       width/height: min(97vw, calc(100vh - 160px), 740px)
       iPad縦（幅768px等）なら最大740pxの大迫力碁盤、スマホ縦でも横幅97%を目一杯使用。
     * 下段（碁盤直下）: 「パス」「待った」「ヒント」「投了」ボタンを碁盤のすぐ下に横一列で配置。
       画面スクロール不要で、手元で確実にワンタップ可能に。
     * 下部ステータスバーをスリム化し、全要素が画面内に100%収まるノースクロール設計を実現。
   - 横向き（PC / タブレット横置き）のレイアウト維持:
     * 左: 白番、中央: 碁盤、右上: 黒番、右下: 操作パネルの3カラムグリッドを最適化。
   - キャッシュ・Service Worker更新:
     * index.html のクエリパラメータを v=1.0.3 に更新。
     * sw.js の CACHE_NAME を igo-dojo-v1.0.3 に更新。
   - 配布パッケージ再同期:
     * dist フォルダの再生成、および C:\git\webapps\igo、W:\igo への再配信完了。

[2026-11-23] バージョン 1.0.2 碁盤サイズ極小化バグ修正＆レイアウト最適化
--------------------------------------------------------------------------------
1. 不具合の事象と原因
   - 事象: PC/ブラウザ表示時に対局画面の中央碁盤が豆粒のように極小化し、
     座標文字（1〜9、一〜九）が重なって盤面をはみ出す表示崩れが発生。
   - 原因: Flexboxコンテナ (.game-main-content) 内において、中央の盤面親要素
     (.board-center-area) に flex: 1 および min-width: 0 が欠落していたため、
     CSSの aspect-ratio: 1/1 と flex-shrink の相乗効果で最小コンテンツ幅 (min-content)
     まで縮小してしまっていた。

2. 修正内容と改善
   - 碁盤サイジングの根本改修:
     * .board-center-area に flex: 1; min-width: 0; min-height: 0; width: 100%; height: 100%; を付与。
     * .igo-board-wrapper の一辺サイズを動的計算式
       width/height: min(calc(100vh - 110px), calc(100vw - 440px), 680px);
       （最小300px〜最大680px）に設定し、画面の主役として大画面で堂々と最大化。
   - 座標ラベルとグリッドアライメントの完全一致:
     * js/board-ui.js に左上角余白 (.board-coord-corner) を追加。
     * .board-coord-row.top を display: grid; grid-template-columns: repeat(9, 1fr); に変更し、
       横1〜9の数字が各マスの列中心と1ミリのズレもなく直上に一致。
     * .board-coord-col.left を display: grid; grid-template-rows: repeat(9, 1fr); に変更し、
       縦一〜九の数字が各マスの行中心と完全に一致。
   - レスポンシブ最適化:
     * タブレット縦向き・スマートフォン表示時のサイズを
       min(94vw, calc(100vh - 220px), 560px) に最適化。
   - キャッシュ・Service Worker更新:
     * index.html のクエリパラメータを v=1.0.2 に更新。
     * sw.js の CACHE_NAME を igo-dojo-v1.0.2 に更新。
   - 成果物再同期:
     * dist フォルダの再生成、および C:\git\webapps\igo、W:\igo への再配信完了。

[2026-11-23] バージョン 1.0.0 プロトタイプ新規構築・初回リリース
--------------------------------------------------------------------------------
1. 開発方針・環境の確定
   - ユーザー確認に基づき、追加ビルドツールやnpmパッケージ等を使わない
     「ビルド不要のPure HTML5 / CSS3 / Vanilla JavaScript (ES6 Modules)」構成を採用。
   - 保守性・可読性に優れ、静的Webサーバーやファイル直接配置でも即時稼働する設計。

2. 画面・UIコンポーネントの実装
   - 画面①：タイトル＆対局設定メニュー画面（#menu-screen）
     * 対戦モード選択（人間 vs AI / 人間 vs 人間 1台共有）
     * AIレベル選択（Lv.1 入門 〜 Lv.4 上級）
     * 手番選択（黒番 / 白番 / ニギリ）
     * ハンデ・置き石設定（互先コミ6.5目 / 2子 / 3子 / 4子局）
     * 初心者サポート設定スイッチ（アタリ警告、着手禁止通知、待った、地合い予測バー、誤タップ防止、効果音）
   - 画面②：対局画面（#game-screen）
     * 木目調質感・枠線・星（天元＋四隅）・座標ラベル（1〜9、一〜九）を備えた9×9碁盤
     * 立体的な碁石描画（ハイライト、シャドウ、光沢）
     * 最終手マーカー、アタリ警告点滅リング、ヒント推奨手マーカー、仮選択ゴースト石
     * プレイヤー情報カード（白番・黒番、手番ハイライト、アゲハマ表示、地合い優勢バー）
     * 操作ボタン（パス、待った、ヒント、投了、着手確定）
   - 画面③：終局・地合い計算＆感想戦モード
     * 連続パス・投了による自動終局判定
     * 地合い自動計算（黒地・白地・ダメの盤面色分けハイライト表示）
     * 終局集計ダイアログ（地、アゲハマ、コミ、合計目数、勝敗）
     * 棋譜再生・感想戦コントローラー（初手 / 1手前 / 1手次 / 終局）

3. 囲碁ルールエンジン (js/igo-engine.js) の実装
   - 9×9盤の連（グループ）探索と呼吸点（ダメ）の精密計算
   - 石の捕獲・アゲハマ処理
   - 自殺手禁止ルール、コウ（同形反復）の禁止判定
   - 局面履歴管理（履歴スタック・クローン・待った対応）
   - 中国ルール／日本ルール対応の地合い判定アルゴリズム

4. AI思考エンジン (js/ai-engine.js) の実装
   - Lv.1 入門: ランダム着手＋即死回避＋取れる石の捕獲
   - Lv.2 初級: アタリ石の捕獲＆逃げ＋天元・星・連結等の好点重視ヒューリスティック
   - Lv.3 中級: モンテカルロ木探索 (MCTS 250シミュレーション) ＋ 簡易UCT
   - Lv.4 上級: 本格モンテカルロ木探索 (MCTS 800シミュレーション) ＋ 開局好点評価
   - 形勢判断・優勢度予測ルーチン（地合い・石数からの勝率予測バー連動）

5. マルチデバイス・ブラウザ対応および画面崩れ防止
   - 実行対象: PC Chrome、iPad Safari、Android Chrome
   - キャッシュ無効化対応:
     * HTMLヘッダー（Cache-Control: no-cache, no-store, must-revalidate / Pragma / Expires）
     * CSS/JS読み込み時のバージョンクエリパラメータ付与
     * Service Worker (sw.js) の Network-First 戦略（最新リソース優先・旧キャッシュ即時クリア）
   - 画面崩れ・誤操作防止:
     * viewport設定（user-scalable=no, viewport-fit=cover）
     * touch-action（碁盤は none、メニューは pan-y）
     * user-select: none によるテキスト選択防止
     * overscroll-behavior: none によるスワイプ引っ張り防止
     * gesturestart / gesturechange / gestureend およびダブルタップ拡大のスクリプト抑止
   - 全画面表示・PWA対応:
     * Chrome: Fullscreen API対応、beforeinstallprompt によるアプリインストール機能
     * iOS Safari: apple-mobile-web-app-capable, apple-mobile-web-app-status-bar-style、
       およびホーム画面追加ガイドモーダルの実装

6. 効果音 (Web Audio API)
   - 外部音声アセットファイルに依存しない、Web Audio APIによるプログラマティック発音
   - 着手音（硬質な石の「パチッ」という音）、捕獲音（ジャラッという爽快音）、アタリ警告音

7. オンラインマニュアルの整備 (manual/index.html, manual/manual.css)
   - 初心者向けの九路盤囲碁基本ルール解説（石の取り方、アタリ、コウ、地合い計算）
   - 各種サポート機能・操作方法の解説
   - PC / iPad / Android 各端末での全画面表示＆ホーム画面追加手順

8. 配布パッケージ・配信対応
   - dist フォルダへ配信用一式をクリーン出力
   - 指定フォルダへの自動配信完了:
     * C:\git\webapps\igo （全ファイル配信済み）
     * W:\igo （全ファイル配信済み）
