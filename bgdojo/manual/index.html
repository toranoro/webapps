1. バックギャモンとは

バックギャモンは、およそ5000年の歴史を持つ世界最古のボードゲームの1つです。 サイコロを振って自分の15枚の駒（チェッカー）を進め、相手よりも早くすべての駒を盤面からゴール（ベアオフ）させたプレイヤーが勝利します。

運（サイコロの出目）と戦略（駒の配置・リスク管理・確率計算）が絶妙に融合した、極めて奥深い頭脳スポーツです。

2. ゲームルール解説

盤面の構成と進行方向

  • 盤面には 1番〜24番 までの24個の三角形（ポイント）があります。
  • 白（あなた）: 24番から1番方向に向かって駒を進めます（1〜6番が白のインナーボード）。
  • 黒（相手/AI）: 1番から24番方向に向かって駒を進めます（19〜24番が黒のインナーボード）。

駒の動かし方と制限

  • ダイスロール: 自分のターンに2個のサイコロを振ります。それぞれの目に応じて駒を前進させます。
  • ゾロ目: サイコロが同じ目（例: 4-4）の場合、その目を 4回 動かすことができます！
  • ブロックポイント: 相手の駒が 2枚以上 あるポイントには進むことができません。
  • ブロットとヒット: 相手の駒が 1枚だけ 置かれているポイント（ブロット）に自分の駒を進めると、相手の駒を「ヒット」して中央の「バー」へ弾き飛ばせます。
  • バーからの復帰（最優先）: バーに自分の駒がある間は、他の駒を一切動かせません。まずバーから相手のインナーボードに出目を使って復帰させる必要があります。
  • 最大出目優先原則: 2つの出目のうち片方しか使えない場合、必ず 大きい方の目 を使わなければなりません。

ベアオフ（ゴール）の条件

自分の 15枚すべての駒がインナーボード（1〜6番ポイント） に集まったとき、初めて駒を盤外へゴール（ベアオフ）させることができます。
  • 出目と一致するポイントからベアオフできます（例: 3が出たら3番ポイントの駒をゴール）。
  • 出目より手前に自分の駒が1枚もない場合、残っている最も遠いポイントからベアオフ可能です。

勝利判定（3種類）

勝利種別 条件 基本獲得点
シングル勝ち 相手がすでに1枚以上ベアオフしている状態で先に全駒ゴール 1 点
ギャモン勝ち 相手が 1枚もベアオフしていない 状態で全駒ゴール 2 点
バックギャモン勝ち 相手が1枚もベアオフしておらず、かつ バーまたは勝者のインナー に相手駒が残っている状態で全駒ゴール 3 点

3. アプリの操作方法

  1. ダイスを振る: 画面右（または下部）の [ 🎲 ダイスを振る ] ボタンを押します。
  2. 駒の移動:
    • 動かせる駒が金色にハイライトされます。
    • 駒をタップ（クリック）すると、移動可能な行き先ポイントが緑色に光ります。
    • 行き先のポイントをタップすると駒が移動します（※行き先が1箇所しかない場合は、駒をタップするだけで自動でスマート移動します）。
  3. 1手戻す（Undo）: 出目を動かした後でも、[ ↩ 1手戻す ] ボタンを押せばターン内の駒移動を何度でもやり直せます。
  4. ターン確定: すべての出目を動かし終えたら [ ✓ ターン確定 ] ボタンを押して相手に手番を渡します。

4. ダブリングキューブとクロフォードルール

盤面中央にある「ダブリングキューブ」は、そのゲームの勝敗ポイントを倍（2, 4, 8, 16...）に吊り上げる駆け引きの道具です。

  • ダブル提案: 自分が有利だと判断したとき、ダイスを振る前に相手にダブルを提案できます。
  • テイク (受託): 相手の提案を受けてゲームを倍率2倍で続行します。キューブの所有権は受託した側に移ります。
  • ドロップ (辞退): 勝ち目がないと判断した場合、即座に1点を相手に与えて投了できます。
  • クロフォードルール: マッチ戦において、どちらかのプレイヤーがあと1点でマッチ勝利となるスコア（例: 5ptマッチで4点）に達した直後の次の1局のみ、ダブリングキューブの使用が禁止されます。

5. アシスト＆AIコーチ機能

  • ピップカウント表示: ゴールまでの残り歩数をリアルタイム表示。形勢判断（レースリード）に役立ちます。
  • 合法手ガイド: ルール上動かせる駒と行き先が一目でわかります。
  • ヒント機能: [ 💡 ヒント ] ボタンを押すと、AIが盤面を瞬時に評価し、おすすめの手（ベスト3）と解説を表示します。
  • 悪手警告: 相手にヒットされやすい危険なブロットを晒してしまうような手を確定しようとすると、確認メッセージで注意を促します。

6. 端末別・快適な遊び方 (PC / iPad / Android)

画面の向き（縦向き・横向き両対応）

iPadやPCでは 横向き（Landscape） にすると、本物のボードのように左右ワイドな大迫力画面で楽しめます。
スマートフォンや片手持ちのタブレットでは 縦向き（Portrait） にすると、盤面と操作ボタンが上下に最適配置され、スクロール不要で快適にプレイできます。

全画面表示 & アプリのインストール (PWA)

  • PC (Google Chrome): ナビゲーションバーの [ 📲 アプリ追加 ] またはアドレスバー右側のインストールアイコンから、デスクトップアプリとしてインストールできます。全画面ボタンでブラウザ枠なしの全画面プレイも可能です。
  • Android (Google Chrome): [ 📲 アプリ追加 ] ボタン、またはブラウザメニューの「ホーム画面に追加」を選択すると、ネイティブアプリ同様に全画面で起動できます。
  • iPad (Safari): 共有ボタン（四角から矢印が出ているアイコン）を押し、「ホーム画面に追加」 を選択してください。ホーム画面のアイコンから起動すると、Safariのアドレスバーが消えて完全全画面のスタンドアロンモードで動作します！

画面の崩れ防止対策

本アプリは誤操作によるピンチズーム、不要なスクロール、テキスト選択を完全に防止するプロテクションを搭載しています。白熱した対局中でも盤面レイアウトが崩れる心配はありません。
