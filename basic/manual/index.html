1. はじめに・動作環境と高速化

Web BASIC 2.0 は、NEC PC-9801 の N88-BASIC を思わせる操作感に、現代の Web 技術（Canvas 2D / Web Audio / PWA）を組み合わせたフルスクリーン BASIC 環境です。

  • 対応ブラウザ：PC版 Google Chrome、iPad Safari、Android Chrome
  • 外部ツール依存なし：100% Vanilla JS で動作し、キャッシュ無効化（常に最新版読み込み）に対応しています。
  • 事前コンパイル型高速VM：プログラム行を事前トークン化＆クロージャコンパイルし、タイムスライス制御で実行するため、MANDEL（マンデルブロ集合）やゲームループが高速に動作します。

基本の操作方法

任意の行に 10 PRINT "HELLO" と入力して Enter を押すとプログラム行として登録されます。行番号なしで RUN と打って Enter を押すと実行されます。上部のファンクションキーボタン（F1 LOAD 〜 F5 CLS、STOP）もタップ・クリックで利用できます。

2. 全画面表示・スマホ / iPad での使い方

PC Chrome / Android Chrome

  • 右上の ⛶ FULL ボタンでワンタッチ全画面表示になります。
  • 📲 APP ボタン（または Chrome メニューの「アプリをインストール」）からスタンドアロンアプリとしてインストールできます。

iPad / iPhone Safari

  • Safari の 共有ボタン（□に↑）→「ホーム画面に追加」 から起動すると、アドレスバーのないフルスクリーンアプリとして使えます。

縦向き・横向き・OS標準キーボード

  • 縦画面・横画面どちらに回転しても、表示領域（VisualViewport）に合わせて自動調整されます。
  • SPLIT ボタンで「グラフィック＋端末の重ね表示」と「画面分割表示（縦時は上下／横時は左右）」を切り替えられます。
  • エディタ領域をタップすると OS標準キーボード が開きます。⌨ KEY ボタンで : ; " ( ) ESC や矢印キーが並んだ 補助キーバー を画面下部に表示できます。
  • 実行中の INKEY$ も、OSキーボードまたは補助キーバーからの入力を受け取ります。
  • 誤操作による画面全体のスクロールやピンチイン・ピンチアウトによるレイアウト崩れは自動的に抑止されます。

3. エディタ・プログラム管理コマンド

コマンド説明
RUN [行番号]先頭または指定行からプログラムを実行します。
STOP / CONT実行を一時中断（STOPボタン/Esc/Ctrl+C）し、CONT で続きから再開します。
LIST [開始][-終了]登録されているプログラムを表示します。（例: LIST 10-50）
NEW / CLEARNEW はプログラムと変数を全消去、CLEAR は変数・配列のみ消去します。
DEL 開始[-終了]指定行または範囲を削除します。（DELETE も可）
EDIT 行番号指定行の内容を末尾に呼び出して編集できます。
AUTO [開始[,増分]]自動で次の行番号を提示します。番号のみの行で Enter または STOP で終了。
RENUM [開始[,増分]]行番号を振り直し、GOTO/GOSUB/THEN/ELSE/RESTORE も自動更新します。
SAVE "名前" / LOADローカルファイル（.bas）としてダウンロード保存 / ファイル選択で読込します。
TSAVE "名前" / TLOAD "名前" / TFILES / TKILL "名前"ブラウザ内部ストレージ（localStorage）に保存・読込・一覧・削除します。（FILES / KILL も可）
SAMPLE [番号|名前]内蔵サンプル一覧を表示、または即時ロードします。
FONT mono|retro|dot表示フォント（OS標準等幅 / レトロ / ドット系）を切り替えます。
SIZE ピクセル数文字サイズを変更します。（例: SIZE 20）
THEME pc98|green|amber|white画面配色テーマを切り替えます。
UPPER on|off表示上の大文字変換を切り替えます。
TRON / TROFF実行中の行番号トレース表示を切り替えます。

4. 基本文・制御構文

命令構文・説明
REM / '注釈（コメント）です。行末まで無視されます。
LET / 代入[LET] A = 10、S$ = "ABC"、I% = 3.8（整数丸め）
IF ... THEN ... [ELSE ...]条件分岐。行番号ジャンプ、マルチステートメント（:）、ネストに対応。
FOR ... TO ... [STEP ...] / NEXT繰り返しループ。単一行内の FOR I=1 TO 10 : ... : NEXT I や複数変数 NEXT J,I にも対応。
WHILE 条件 / WEND NEW条件が真（0以外）の間繰り返します。
REPEAT / UNTIL 条件 NEW後判定ループ。条件が真になるまで繰り返します。
GOTO 行 / GOSUB 行 / RETURN [行]無条件ジャンプとサブルーチン呼び出し。
ON 式 GOTO|GOSUB 行1,行2,... NEW式の値（1, 2, 3...）に応じて分岐します。
ON ERROR GOTO 行 / RESUME [NEXT|行] NEW実行時エラーの捕捉と復帰（ERR, ERL 参照可）。
WAIT ミリ秒 / SLEEP 秒 / VSYNC指定時間待機、または画面リフレッシュ（60fps）同期。
END / STOPプログラムを終了または一時中断します。

5. テキスト入出力・データ・配列

命令構文・説明
PRINT / ?文字列や式を出力。; で連結・改行抑制、, で14桁タブ区切り、TAB(n) / SPC(n) 対応。
PRINT USING "書式"; 式... NEW数値桁揃え（###.##, ###,###, $$###）や文字列整形（&, !, \ \）。
INPUT ["案内";] 変数,...キーボードからの入力を受け付けます。カンマ区切りで複数変数可。
LINE INPUT ["案内";] 変数$ NEWカンマを含めて1行まるごと文字列変数に読み込みます。
DIM 配列名(サイズ[,...]) NEW1次元・多次元配列を確保します（例: DIM M(20,20), N$(10)）。
DATA / READ / RESTORE [行] NEWプログラム内の固定データを順次読み込みます。
SWAP a, b NEW2つの変数（または配列要素）の値を入れ替えます。
DEF FN名前(引数) = 式 NEWユーザー定義関数を定義します（例: DEF FNSQ(X)=X*X）。
MID$(変数$, 位置[, 長さ]) = 式 NEW文字列変数の一部を書き換えます。
RANDOMIZE [シード] NEW乱数系列を初期化します。

6. グラフィックス命令

命令構文・説明
SCREEN w, h / SCREEN モード解像度変更（例: SCREEN 640,400）。モード番号: 0=非表示, 1=320x200, 2=640x200, 3=640x400, 4=640x480。
GFX ON|OFF / CLS [1|2|3]CLS 1=テキスト消去、CLS 2=グラフィック消去、CLS 3=両方消去。
COLOR 前景[,背景] / BG 色パレット番号（0〜15）、#RRGGBB、R,G,B、色名（"RED" 等）を指定。
PALETTE 番号, 色 / PALETTE 番号,R,G,B NEWパレット0〜15の色を再定義します。
ALPHA 値 NEW描画の不透明度（0.0〜1.0）を設定します。
PSET [STEP] (x,y)[,色] / PLOT x,y1ピクセル点を描画します。PRESET は背景色で消去します。
LINE (x1,y1)-(x2,y2)[,色][,B|BF][,style]直線または矩形（B=枠, BF=塗りつぶし）を描画。LINE x1,y1,x2,y2 や -(x2,y2) も対応。
RECT x1,y1 TO x2,y2 [FILL] / BOX矩形を描画します。
CIRCLE (cx,cy),r[,色[,開始角,終了角[,縦横比[,F]]]]円・楕円・円弧・扇形を描画します。従来形式 CIRCLE cx,cy,r [FILL] も可。
PAINT (x,y)[,塗色[,境界色]] NEW指定座標から閉じた領域を高速スキャンライン塗りつぶしします。
TRIANGLE x1,y1,x2,y2,x3,y3[,色][,FILL] NEW三角形を描画・塗りつぶしします。
LOCATE x, y / SYMBOL (x,y),文[,sx[,sy[,色[,角度]]]]LOCATE 直後の PRINT、または SYMBOL で任意座標・拡大・回転文字を描画します。
WINDOW (x1,y1)-(x2,y2) / VIEW (x1,y1)-(x2,y2) NEW論理座標系（WINDOW）とクリッピング領域（VIEW）を設定。引数なしで解除。
ROLL dx, dy NEWグラフィック画面全体を dx, dy ピクセルスクロールします。
GSAVE id,x1,y1,x2,y2 / GPUT id,x,y[,mode] NEW矩形画像をスプライト登録し、PSET / TRANS / XOR / OR / AND で高速描画します。（GET / PUT 構文も可）

7. サウンド・MML (PLAY)

命令説明
BEEP [周波数, ミリ秒]ビープ音を鳴らします（省略時 880Hz, 120ms）。
SOUND 周波数, ミリ秒 NEW指定周波数・長さのPSG矩形波を鳴らします。
PLAY "MML文字列" NEW音楽マクロ言語（MML）をバックグラウンド再生します。

MML コマンド一覧

C D E F G A B（音名、#/+ で半音上、- で半音下）、R（休符）、O1〜O8（オクターブ）、< >（オクターブ上下）、L1〜L64（標準音長）、.（付点）、T32〜T255（テンポ）、V0〜V15（音量）、M0〜M3（波形: 0矩形 / 1三角 / 2ノコギリ / 3正弦）、&（タイ）。

PLAY "T140 O4 L8 V10 C D E F G A B > C4"

10. サンプルプログラム

アプリ内の SAMPLE ボタン（または SAMPLE "MANDEL" コマンド）ですぐに実行できます。エディタへ直接コピー＆ペーストすると自動的に行番号付きプログラムとして一括登録されます。

10 SCREEN 640,400 : CLS 3
20 WINDOW (-2,-1.5)-(2,1.5)
30 COLOR 5 : LINE (-2,0)-(2,0) : LINE (0,-1.5)-(0,1.5)
40 COLOR 6
50 FOR X=-2 TO 2 STEP 0.02
60 Y=SIN(X*3)*COS(X)
70 IF X=-2 THEN PSET (X,Y) ELSE LINE -(X,Y)
80 NEXT X
90 END
