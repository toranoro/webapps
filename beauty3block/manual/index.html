1. 基本ルール（コラムス）

  • フィールドは 横6列 × 縦13段 です。上から3個セットの宝石（コラム）が落下してきます。
  • 同じ種類の宝石を 縦・横・ナナメ（斜め） のいずれかの直線上に 3個以上 並べると消滅します。
  • 宝石が消えて上の宝石が落下した際、さらに3個以上揃うと 連鎖（CHAIN） が発生し、倍増した高得点を獲得できます。
  • 中央列の天井より上に宝石が積み上がるとゲームオーバーになります。
プリズムジュエル（特殊宝石）： 宝石を一定数消すごとに、虹色に輝くプリズムジュエルの列が出現します（設定でON/OFF可能）。着地した真下にある宝石と同じ種類の宝石をボード上からすべて一掃します！

3. 操作方法

PC（Chrome キーボード操作）

キー動作
← → / A D / J L左右へ移動（長押しで連続移動）
↑ / W / X / I3つの宝石の並び順を入れ替え（下方向へシフト。Z で逆シフト）
G / F3ブロック全体を90°回転（G: 時計回り、F: 反時計回り。横向き配置が可能！）
↓ / S / K少し落ちる（高速落下・ソフトドロップ）
Space一気に落下して固定（ハードドロップ）
P / Escポーズ / 再開（ポーズ画面の「タイトルに戻る」でBGMも停止します）
M効果音 ON・OFF（全画面は画面上の ⛶ ボタンまたは F11）

iPad・Android タブレット・スマートフォン（タッチ操作）

  • 画面下部のタッチパッド： ◀ / ▶ で移動、▼ で高速落下、⤓ でハードドロップ、⇄（SWAP）で宝石入れ替え、↷（ROT）でブロック90°時計回り回転が行えます。
  • ボード直接ジェスチャー： ボード上をタップすると宝石入れ替え、上スワイプでブロック90°回転、左右スライドで移動、下ドラッグで高速落下、素早い下フリックでハードドロップができます。
  • 縦向き・横向き対応： PC・タブレットでは縦向き・横向きの両方でプレイ可能です。スマートフォンでは縦向き表示に最適化されており、横向きにした場合は縦向きへの回転案内が表示されます。

4. 全画面表示・アプリインストール（PWA）

PC Chrome / Android Chrome の場合

  • 画面上の ⛶（全画面） ボタンでブラウザUIを隠した全画面モードに切り替えられます。
  • HTTPS または localhost 環境でアクセスすると、画面内の 「📲 アプリをインストール」 ボタン（またはブラウザのアドレスバーのインストールアイコン）からアプリとして端末にインストールできます。

iPhone / iPad Safari の場合

  1. Safari の共有ボタン（□↑）をタップします。
  2. 「ホーム画面に追加」 を選び、追加します。
  3. ホーム画面の Beauty3Block アイコンから起動すると、アドレスバーのない全画面アプリとして遊べます。

5. BGM・難易度・設定オプション

  • BGM設定（タイトル画面・設定モーダル）： asset/music/ 内の OGG 楽曲を 🔀 ランダム再生 または 🔁 1曲リピート（曲選択）で再生できます。⏭ ボタンで次の曲へスキップできます。
  • Relax： 宝石が5種類・落下速度もゆったりで、じっくり連鎖を楽しめます。
  • Classic： 宝石が6種類・標準的なコラムスバランスです。
  • Master： 落下速度が速く、スリリングなスピード勝負を楽しめます。
  • 横画面タッチパッド表示： iPad や Android タブレットを横向きで持つ場合も、設定から画面下部にタッチボタンを表示できます。
